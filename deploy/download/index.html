Quipcall for Mac

Alpha · Apple Silicon and Intel · macOS 12.3 or later (screen sharing needs macOS 14)

Install with one line (easiest)

Open Terminal and paste:

curl -fsSL https://quipcall.com/download/install.sh | sh

Puts Quipcall in Applications and opens it. Run it again to update.

Or download it

Apple Silicon (M1 and later) Intel

Not sure? Apple menu → About This Mac: “Chip: Apple M…” is Apple Silicon, “Processor: … Intel” is Intel.

  1. Unzip it and drag Quipcall into Applications.
  2. The first time, macOS refuses to open it: the alpha isn't notarized by Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Quipcall.

Permissions

  • Microphone and camera: macOS asks the first time you use them.
  • Screen sharing: the first time you share, allow Quipcall under System Settings → Privacy & Security → Screen & System Audio Recording, then quit and reopen Quipcall.

Something broke?

Send the log: ~/Library/Logs/Quipcall/quipcall.log (in Finder: Go → Go to Folder…, paste the path).
